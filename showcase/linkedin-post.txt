English

This is honestly mind-blowing!

I just used GPT-5.5 in Codex to implement a full tab system in the open source Excalidraw repo, starting from one initial prompt.

The feature: Excalidraw currently works with one infinite canvas at a time. I wanted something closer to draw.io, where users can keep multiple drawings open and switch between them using tabs.

And Codex helped build it end to end:
- local drawing persistence
- active drawing switching
- import/share flows creating new drawings instead of overwriting work
- a bottom tab switcher UI
- formatting, type checking, linting
- branch, commit, and push

This is the kind of feature many developers and users have wanted for a while, and seeing it come together from a single prompt is wild.

It is not just a coding agent anymore. It is becoming a real coding partner.

And yes, I named it ExcaliTabs.
